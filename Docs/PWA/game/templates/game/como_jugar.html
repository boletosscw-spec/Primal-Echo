Aprende el ritmo del eco.

Controles documentados para la versión de Unity. La PWA es una guía del proyecto; no incluye una versión jugable web.

Teclado y mando

Controles del juego
Acción Teclado / ratón Xbox
Moverse / dirigir A/D o flechas Stick / cruceta
Salto y doble salto Espacio A
Lanza / pogo J / Z / clic izquierdo; abajo en el aire para pogo X
Dash Shift / C RB / RT
Arco K / X / clic derecho Y
Fijar apuntado Ctrl + dirección LT + dirección

El README también enumera bloqueo con L/F o LB. Se encontró su animación, pero no una reducción de daño asociada en el sistema de vida: no lo tomes aún como defensa confirmada.

Busca las farolas

Al quedarte sin vida vuelves al último checkpoint con la vida llena. Los peligros pueden devolverte al suelo seguro con pérdida de vida.

Controla la distancia

Kael se detiene mientras tensa y suelta el arco. Anticipa la embestida de los robots y usa la lanza para atacar cerca.

Explora las alturas

Combina doble salto y dash. Los géiseres impulsan a Kael; las piedras quebradizas exigen moverse rápido. Los fragmentos de eco son opcionales.
